# AI Capstone Project

> **Status:** Early setup. The tooling is set up, but no features have been built yet.

## Overview

This repository holds the capstone project for the **Frontend AI Engineering** track. It will be a frontend application with AI-powered features, built up step by step over the course of the track.

The repository is being set up as part of the **FE-01: Environment and AI Toolchain** assignment.

## Tech Stack

- **React**: UI library
- **JavaScript**: main language
- **Tailwind CSS**: styling
- **Vite**: build tool and dev server
- **Vitest** + **React Testing Library**: testing

## Development Tools

- **Claude Code**: AI-assisted development. This is not part of the application stack. Guidelines for AI assistants working in this repository are in [CLAUDE.md](CLAUDE.md).

## Development

### Prerequisites

- [Node.js](https://nodejs.org/) 22 (22.13 or newer) or 24 LTS
- npm (comes with Node.js)
- Git

### Getting Started

```bash
# Clone the repository
git clone <repository-url>
cd ai-capstone-project

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm test` | Run tests in watch mode |
| `npm run test:run` | Run all tests once |
